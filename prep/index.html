Eight evidence-based protocols

How NeuroPrep hardens intuition

01

Spaced Repetition

Expanding intervals (10m → 1d → 3d → 7d → 30d) aligned to Ebbinghaus forgetting curve. Each successful recall doubles memory half-life. FSRS-4.5 inspired.

Ebbinghaus 1885; Cepeda et al. 2008
02

Active Recall & Testing Effect

Retrieval before feedback strengthens traces 50% more than re-reading. You answer first, then get elaborated feedback. Desirable difficulty.

Roediger & Karpicke 2006
03

Interleaving

Mixed subjects force discrimination. Prevents category cueing, builds transfer & inductive reasoning — critical for CSS essay & précis.

Kornell & Bjork 2008; Rohrer 2012
04

Dual Coding & Elaborative Interrogation

Verbal + visual + intuition anchor. Why does this answer make sense? Linking to prior knowledge builds associative networks.

Paivio 1986; Pressley 1987
05

Leitner + Confidence Calibration

5-box system + metacognitive confidence 1-5. High-confidence errors trigger hypercorrection — strongest neuroplastic window.

Leitner 1972; Dunlosky & Rawson 2012
06

Misconception Weeding (Conceptual Change)

Diagnose, confront, replace false mental models. Trap analysis + verified intuition hardens correct schema.

Chi 2013; Vosniadou 1994; Posner 1982
07

Knowledge Graphs & Transfer

See how CSS subjects connect: Pol Sci → Constitutional Law → Current Affairs. Graph reveals gaps, strengthens schema transfer.

Novak & Cañas 2008
08

Sleep, Circadian & Ultradian

Review timing respects memory consolidation windows. Pomodoro (25/5) aligns to ultradian rhythm. No-screen mode reduces blue light & eye strain.

Diekelmann & Born 2010; Walker 2017
